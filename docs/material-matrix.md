Originaldateien und Musterlösungen bleiben lokal. Öffentliche Beispiele werden
eigenständig formuliert. Das Arraymodell wird von der dynamischen Python-Liste
unterschieden. Eine Größenänderung allein erzwingt keine verkettete Liste;
die Wahl hängt auch von Zugriffen und Operationen ab. Schleifenausgabe aus
L1_2 wird in L1.3 vertieft, damit neue Lernende zunächst den Indexzugriff lernen.
